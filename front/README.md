# Front (SPA React)

Vite + React + TanStack Router + HeroUI. Voir `docs/specs-techniques.md` et `agent.md`.

## Environnement d'exécution

**Aucune commande ne s'exécute en local** : pnpm, Biome, tsc, Vitest, Playwright… tournent impérativement dans les conteneurs Docker (`docker compose exec node …`, `docker compose run …`). Voir la règle « Environnement d'exécution » dans `agent.md`.
